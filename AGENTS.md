# AGENTS.md — rules for any coding agent working in this repo

Project: **20 Hour Weeks** — a Roblox horror game set inside a 1:1 recreation of George Mason University's
Recreation and Athletic Complex (RAC), Fairfax campus. Top priority: the RAC must be dimensionally and
visually faithful to the real building. Gameplay is intentionally simple for now.

## Sources of truth (read before building anything)
- `docs/SPEC.md` — what we are building and the quality bar.
- `docs/MILESTONES.md` — ordered work list; do only the milestone you were given.
- `blueprint/` — measured building data (feet). Geometry code must read from here, never hard-code guesses.
- `reference/` — photos (`photos/`, `thumbs/`, contact sheets in `sheets/`), architect drawings
  (`photos/Screenshot_*.jpg`, Perkins&Will, 1/32" = 1'-0"), `site_plan_native.png` (scale bar: 0–100 ft),
  OpenStreetMap data (`osm_rac_area.json`). `reference/` media is git-ignored; never commit it.

## Units and axes
- **1 stud = 1 foot.** Origin (0,0,0) = the RAC main entrance exterior threshold at Level 1 finished floor.
- +X = east, −Z = north (Roblox convention: LookVector of north-facing = (0,0,-1)). Level 2 finished floor = `blueprint` value.

## Hard rules
1. Code lives in `src/` and syncs with Rojo (`default.project.json`). Never edit synced scripts only in Studio.
2. Geometry is **generated by code from `blueprint/` data** (builder modules), then committed to the place by running the
   builder in Edit mode via the Studio MCP. Hand-placed one-offs must be recorded in `blueprint/` as props.
3. Anchor everything static. Keep collision simple (CanCollide off on trim/detail, `CollisionFidelity=Box` on meshes).
   Budget: < 25k parts for the whole map; use MeshParts/instancing for repeated props.
4. Realism: use Roblox materials + `MaterialVariant`s (MaterialService) for maple hardwood, terrazzo, porcelain tile,
   carpet tile, painted CMU block, brick, acoustic ceiling tile. Lighting `Technology = Future`.
5. **No real people.** The villain is a fictional character called "Coach". Never use a real person's name, face, or
   photo for any character, texture, decal, or sound. Never use reference photos that contain people as textures.
   The distraction item is the **"Geak Bar"** — an energy bar (food), never a vape.
6. Verify before claiming done: `pwsh tools/verify.ps1` must pass, and Studio checks (below) must pass.
7. Do not publish the place to Roblox. Do not delete or rename things outside the milestone's scope.
8. Small, focused modules. `--!strict` at the top of new Luau files. No `wait()`; use `task.*`.

## Studio verification (via Roblox_Studio MCP)
- After building: `get_console_output` must show no errors/warnings from our scripts.
- Play test: `start_stop_play` → run for ≥20 s → capture console → stop. No errors.
- Visual: `screen_capture` from the camera stations in `blueprint/photo_stations.json`, saved to
  `verification/<milestone>/<photo>.png`, and compared against `reference/photos/<photo>.jpg`. Record a
  pass/fail + notes per station in `verification/<milestone>/REPORT.md`.

## Reporting
End every task with: what changed (files), verify.ps1 result, Studio console result, screenshots taken, known gaps.
Never claim something passed that you did not run.
