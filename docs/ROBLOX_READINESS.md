`LightingBuild` places one SpotLight per fixture, `Shadows = false`. Keep that: 392 shadowed Future lights would stall mobile. Sun `GlobalShadows` stays on (`RACBuild.server.luau`). `Perf.apply` turns `CastShadow` off on parts whose longest axis is under 2 ft.

## Streaming

Recommended Workspace (set in the place, not generated by the builder):

- `StreamingEnabled = true`
- `StreamingMinRadius = 64` (studs/ft)
- `StreamingTargetRadius = 256`
- `StreamingIntegrityMode = MinimumRadiusPause`

`Perf.apply` (last call in `Build.build`):

```lua
Perf.apply(model)
```

- RAC model: `ModelStreamingMode = Persistent` (always present around spawn).
- Repeated props of the same `Kind` (2+) parented into `{kind}_group` Models with `ModelStreamingMode = Atomic`.
- Singleton prop models: Atomic.

## Collision

- Static geometry remains Anchored.
- Decorative / non-interactive parts: `CanTouch = false`, `CanQuery = false`.
- Trim, detail, and parts with a min axis &lt; 0.5 ft: `CanCollide = false`, except floors, stairs (treads/risers/stringers), walls, columns, roofs, spawn, and furniture bodies (`SOLID_KIND` volume ≥ 0.45 ft³).
- Mesh collision: Box.
- Collision groups: default `Default` is enough for the static building. Add a `Characters` / `Ghost` pair only when Coach needs to walk through crowds; do not put walls in a non-colliding group.

## Mobile

- 392 unshadowed fixture lights + Future lighting is the main GPU cost. If a low-end device drops below 30 FPS in the gym, drop high-bay count or switch gym fixtures to SurfaceLights without shadows (already the case).
- Part count ~24.5k is acceptable with streaming; Atomic prop groups keep treadmills from popping half-assembled.
- Touch: doors use ProximityPrompt, not Touched.

## Memory (offline rbxm)

`places/build.rbxm` on disk is the geometry payload. In-Studio client memory must be captured during play (see `verification/readiness/`). Expect the RAC model in the low hundreds of MB with MaterialVariants; streaming should keep the working set to the streamed radius.
