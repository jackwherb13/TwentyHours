# Milestones

The loop driver (`tools/grok-loop.ps1`) takes the first unchecked milestone, hands it to Grok with AGENTS.md rules,
runs verification, and only checks it off after `tools/verify.ps1` passes AND an independent audit pass says PASS.
Each milestone's **Done when** list is the acceptance test. Work only inside the milestone's scope.

- [ ] M1 Blueprint — measured building data
  - Trace the RAC from `reference/site_plan_native.png` (scale bar 0–100 ft at bottom-left; measure it in pixels),
    the Perkins&Will drawings (`reference/photos/Screenshot_*.jpg`, Level 1/2/3 plans) and the OSM outline
    (`reference/osm_rac_area.json`, way 112472416) into `blueprint/level1.json`, `blueprint/level2.json`,
    `blueprint/site.json` (units: feet; axes per AGENTS.md).
  - Schema (document it in `blueprint/SCHEMA.md`): rooms {id,name,type,polygon,floorMaterial,ceilingHeight,ceilingType},
    walls {a,b,thickness,height,material,openings:[{type:door|window|opening|curtainwall,offset,width,sill,head}]},
    columns, stairs {polygon, rise, run, fromLevel, toLevel}, voids (double-height "open to below"), exterior facade
    segments {a,b,style:brick|precast_band|metal_panel|curtain_wall,height}, roofs {polygon,height}, props anchors.
  - Heights: derive and document in `blueprint/HEIGHTS.md` with the photo evidence used for each number.
  - `blueprint/photo_stations.json`: for every reference photo that shows the building, an estimated camera
    position (x,y,z ft, eye height ~5.2), look direction, and vertical FOV (iPhone main camera ≈ 55° vertical for portrait).
  - `tools/overlay.py`: renders the blueprint polygons over `site_plan_native.png` and over the OSM outline into
    `verification/M1/overlay_*.png`, and prints footprint IoU vs OSM.
  - **Done when:** overlay IoU vs OSM footprint ≥ 0.92; every room visible in the site plan exists in level1.json;
    Level 2 rooms from the drawings exist in level2.json; HEIGHTS.md cites evidence for every height; JSON validates
    against SCHEMA.md via `lune run tools/validate_blueprint.luau` (write it).

- [ ] M2 Builder — shell from data
  - `src/ReplicatedStorage/RAC/Build/` modules: `Blueprint` (loads JSON from ModuleScripts generated by
    `tools/json2luau.py`), `Walls` (walls with CSG-free openings: split wall into segments around openings),
    `Floors`, `Ceilings`, `Stairs`, `Facade`, `Roofs`, `Build` (entry; builds into `workspace.RAC`, idempotent).
  - Replace/retire the old hard-coded `RACArchitecture`/`RACProps` layout (keep their good ideas; keep DoorService,
    LightingController and RACSystems working by producing the same tagged instances they expect — read them first).
  - Run the build in Studio Edit mode via MCP so geometry persists in the place.
  - **Done when:** build runs with zero console errors; part count logged and < 12k for the shell; top-down
    screen_capture of Level 1 overlaid/compared with the site plan looks aligned; walking test: character can walk
    from the main entrance to every gym and up the stairs to Level 2 without getting stuck (use character_navigation).
